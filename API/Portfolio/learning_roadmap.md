# Learning Roadmap

## Semester 1 – Foundations
- Learn Python programming fundamentals.
- Practice Linux commands and shell scripting.
- Understand Git and GitHub.
- Learn HTML and CSS basics.
- Complete DeveloperPortfolio capstone project.

## Semester 2 – Core Computer Science
- Learn Data Structures.
- Study Database Management Systems.
- Improve problem-solving skills.
- Build basic web development projects.
- Complete one certification.

## Semester 3 Onwards – Specialization
- Learn advanced Python.
- Start Artificial Intelligence and Machine Learning.
- Practice DSA regularly.
- Build real-world projects.
- Prepare for internships and placements.

## Long-Term Goal
Become an AI/ML Engineer with strong programming, problem-solving and practical project skills.
